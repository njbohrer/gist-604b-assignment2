# gist-604b-assignment2
GIST 604B Assignment 2: QGIS Desktop GIS Projects  
  
A. Overview:
##
i. This repository represents sharing, and showing QGIS project files. It demonstrates basic geoprocesseing techniques from the non Esri based open source software Quantum GIS. It also shows basic repositry organization that can be helpful when working on projects longterm that require sharing files with others.
##
ii.  These QGIS tutorials cover the major fundamentals of a GIS professional. From creating maps to share as layouts, to using and reprojecting coordinate systems, they support deeper analysis. This enables spatial processing and more advanced location-based tools to select and analyze specific data of interest. Tabular data can be linked to existing geometries, and geometries can even be created from spreadsheets. The Processing Modeler allows for repeatable, automated workflows, and serves as QGIS’s version of Esri’s ModelBuilder.   
##
B. Software Environment:
##
i. Version: QGIS Desktop 4.0.0
##
ii. OS: Windows 10
