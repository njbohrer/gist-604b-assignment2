## Project Description
This project demonstrates foundational GIS workflows using QGIS. The assignment focuses on core desktop GIS capabilities including map creation, coordinate system management, spatial analysis, and workflow automation. It highlights how open-source GIS tools can be used to perform professional-level geospatial analysis outside of the Esri ecosystem.

---

## Tools and Technologies
- QGIS  
- GeoPackage, Shapefile, CSV  
- Processing Modeler (QGIS)  

---

## What I Did
- Created map layouts with essential cartographic elements (legend, scale bar, export formatting)  
- Managed coordinate reference systems (CRS) and performed reprojection workflows  
- Edited attribute tables and executed field calculations for data transformation  
- Converted tabular data (CSV/Excel) into spatial datasets  
- Applied vector and raster symbology for data visualization and analysis  
- Performed table joins and spatial joins to integrate datasets  
- Executed spatial and attribute queries to extract targeted data  
- Built automated workflows using QGIS Processing Modeler  

---

## How to View / Run
- Open the `.qgz` project file in QGIS  
- Ensure all referenced data files (GeoPackage, shapefiles, rasters) remain in their original folder structure  
- Navigate through layers and layouts to explore completed exercises and outputs
