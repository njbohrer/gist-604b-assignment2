# gist-604b-assignment2
GIST 604B Assignment 2: QGIS Desktop GIS Projects  
  
A. Overview: <br> <br>
i. This repository represents sharing, and showing QGIS project files. It demonstrates basic geoprocesseing techniques from the non Esri based open source software Quantum GIS. It also shows basic repositry organization that can be helpful when working on projects longterm that require sharing files with others.<br> <br>
ii.  These QGIS tutorials cover the major fundamentals of a GIS professional. From creating maps to share as layouts, to using and reprojecting coordinate systems, they support deeper analysis. This enables spatial processing and more advanced location-based tools to select and analyze specific data of interest. Tabular data can be linked to existing geometries, and geometries can even be created from spreadsheets. The Processing Modeler allows for repeatable, automated workflows, and serves as QGIS’s version of Esri’s ModelBuilder.

E. Reflection: <br> <br>
Intially, working in QGIS was overwhelming, but I quickly realized I understand the proccesses occuring deeply from my background with Esri software. It took a bit, but overall I enjoyed working with this open source software. QGIS projects (.qgz) mainly act as pointers to separate data files (Shapefiles, GeoPackages, rasters), while ArcGIS Pro projects (.aprx) are more tightly tied to Esri geodatabases. The key difference is QGIS is file-based and flexible, whereas Esri centers workflows around structured geodatabases for data management and rules. I struggle with understanding all the different functions on Github, but still so much to learn! I plan on using these skills as a work around for Esri licensing, and I intend to keep QGIS as a great back up plan.
